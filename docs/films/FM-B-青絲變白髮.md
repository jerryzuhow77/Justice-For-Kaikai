# FM-B｜青絲變白髮

狀態：V8.0 結案版  
片長：73 秒  
專屬配樂：`public/media/film-one-year-old.m4a`  
Runtime：`assets/data/film-productions.js` → `FM-B`

## 定位

以一縷青絲作為材質接力：清代厝埕的婦女群像 → 急診布簾與護士 → 法院旁聽婦女 → 外婆證人席。白髮不是奇幻變老，而是時間、等待與失去累積後的視覺落點。

## 來源與倫理

- 清代三名婦女是文學化群像，不是歷史證詞。
- 兩名護士對話永久標示為匿名來函情境重構／非真實錄音。
- 法院旁聽者是藝術化群像，不冒充證人證詞。
- 外婆段只使用既有庭訊／專題整理語句，不新增台詞。
- 不追拍外婆哭泣或離場；結尾鏡頭留在麥克風、面紙與空證人席。
- 播放逐句文字以 `film-productions.js` 為準。

## 角色

- 清代婦女三名：不同年齡、髮髻與細微姿勢，避免複製同一人像。
- 護士兩名：醫療工作中的克制側視，不靠近或重建兒童傷勢。
- 法院女性群像：青絲、夾白、灰白髮自然銜接。
- 外婆：中年、已有灰白髮；在**證人席**，不是旁聽席。

## GSAP 時間軸結構

- 五幕以 `film-productions.js` act 時間鎖定。
- 幕 1 人物採「一人先動、另一人後反應」，不做群體同步機械動作。
- 幕 2 急診不呈現病床、傷口或孩子痛苦影像；只以布簾、推車、紀錄筆與工作反應承接。
- 幕 3–4 是「髮絲材質接力」核心：從黑髮、布簾纖維、卷宗紙紋到白髮，必須看得出同一條視覺線索。
- 幕 4 的停頓以 runtime silent window／cue 控制，不另造更長煽情停格。
- 手機版以人物半身、髮絲與證人席局部重新構圖，不把橫向群像硬縮成小圖。
- 低動態版保留五張關鍵畫面＋逐字稿與來源標籤。
