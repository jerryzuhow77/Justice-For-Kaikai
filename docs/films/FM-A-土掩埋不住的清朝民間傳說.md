# FM-A｜土掩埋不住的清朝民間傳說

狀態：V8.0 結案版  
片長：155 秒  
專屬配樂：`public/media/film-stamped-in-marble.m4a`  
Runtime：`assets/data/film-productions.js` → `FM-A`

## 定位

清代民間傳說意象 × 現代司法終局。傳說只提出問題；現代法院段落把敘事從因果與報應，轉回刑責、制度與活著的大人。

## 來源與倫理

- 民間傳說、兄嫂與椅仔姑段落屬文學／藝術演繹。
- 不呈現兒童遺體、傷口、施虐畫面或獵奇死亡細節。
- 法院與離庭畫面為藝術化合成；司法結果摘要依既有來源層級呈現。
- 兩名現代被告在法院與離庭畫面維持上銬，不以快門效果美化或娛樂化。
- 播放逐句文字以 `film-productions.js` 既有 cue 為唯一 runtime 版本，本文件不另寫角色新台詞。

## 角色

- 椅仔姑：清代臺灣閩南女童，約三歲；完整、無傷、非肖像化。
- 兄、嫂：清代民間人物，服裝與場景符合古厝語彙。
- 現代兩名被告：深色囚服、上銬，非宣傳式英雄構圖。
- 法官、記者與觀察者：服務司法轉場，不搶走案件資訊本身。

## GSAP 時間軸結構

- 每幕使用既有 act start/end，不任意延長 cue。
- 主 timeline 僅控制鏡頭、光影、材質與字幕節奏；角色台詞時間以 runtime cue 為準。
- 幕 2 的門栓顫動最多三次，不製造恐怖遊戲 jump-scare。
- 幕 3 是全片關鍵 match cut；桌機可保留較完整材質融合，手機改以中央門縫／階梯局部完成轉場。
- 幕 5 快門亮度與頻率須受低動態模式控制；低動態版改為靜態曝光卡。

## 配樂

`Stamped in Marble` 對應本片。開場淡入、法院資訊出現時 duck；尾段在最後責任句前進入淡出，不覆蓋司法文字。
