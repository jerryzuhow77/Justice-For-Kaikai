## 3. 24場共同演出規格

每場都具備：

1. 穩定`scene_id`。
2. 固定材料性質／來源牌。
3. 10個不同姿勢或非語言動作節拍。
4. 10格可點擊分鏡。
5. 遊戲式逐句對話框。
6. 上一句、下一句、播放、暫停、完整逐字稿。
7. 16:9桌機舞臺與9:16手機重構。
8. `prefers-reduced-motion`及手動低動態模式。
9. JavaScript停用時的完整文字入口。
10. 對話與分鏡描述分離；製作動作不會被誤當成案件人物原話。

自動播放並非影片檔，而是資料驅動的即時場景播放器：播放器依對話長度安排停留，動作節拍與對話節拍可分開；長場次如`FM-A`、`DV04`與`FM-C`不會因台詞較多而截斷。

### 3.1 GSAP時間軸規格

- 使用本地封裝`GSAP 3.13.0`與`ScrollTrigger 3.13.0`，不依賴CDN。
- 每場開啟時才建立一條獨立timeline，關閉播放器即`kill()`釋放；首頁不一次初始化24條長時間軸。
- 每個對話節點建立穩定`step-N`標籤；十組非語言動作仍映射至十格分鏡。
- 每拍由文字長度計算3.2–8.4秒停留；人物動作、背景推鏡、霧層、焦點光、紙紋、退紅線、對話框與計數器在同一條時間軸同步。
- 皮影第一拍完整幕開，末拍幕謝至保留門形縫隙；側視劇場以緩慢橫移與人物微動為主；電影場以四聯概念圖做材質匹配與分段推鏡。
- 播放器提供播放／暫停、上一拍／下一拍、十格跳轉及可拖曳的整場進度條。
- 首頁只由ScrollTrigger負責卡片與章節進場；正文對話不綁捲動，避免閱讀疲勞。
- `gsap.matchMedia()`分開桌機、手機與系統低動態；手動低動態會立即銷毀timeline並顯示靜態關鍵幀。
- GSAP若未載入，舊式計時播放器接手；JavaScript若完全停用，`story.html`與母稿下載仍可使用。

### 3.2 十姿勢連續化

男女守門人的十組姿勢不是單張圖反覆淡入，而是分別控制：整體位移、重心升降、軀幹旋轉、頭部角度、左臂與右臂。側視人物把位移幅度縮至72%，皮影保留完整幅度；電影場隱藏通用守門人，改由概念圖內角色與鏡頭運動承擔表演。

## 4. 對話規則

- 十場皮影：完整保留V6的`S00-L01`至`S09-L06`。
- 十場側視：使用V6 Scene Manifest既有側視導讀句；`DV04`完整保留V6急診來函情境重構對話。
- `FM-A`：使用V6 PART III-C既有兄、嫂、椅仔姑、司法旁白與男女皮影觀察者原句。
- `FM-D`：只使用V6第08篇與外婆段已存在的句子；不補寫外婆的新台詞。
- `FM-B`：清代婦女的文學化群像取用V6第01篇既有皮影原句；兩名護士只使用V6急診來函重構原句；外婆只使用既有整理文字。
- `FM-C`：完整使用V6 PART III-D象徵性對話，永久標示不是兩名兒童的真實言語、證詞或臨終陳述。

## 5. 四部電影的角色與畫面限制

### FM-A｜土掩不住的名字

- 椅仔姑是清代臺灣閩南女童，完整、無傷、非真實肖像。
- 兄嫂掩埋只以泥土、舊蓆、髮簪與椅腳暗示，不呈現遺體。
- 現代兩名被告穿深藍色囚服、上銬，在法庭內聽候判決；走出法院仍上銬。
- 法院場景為藝術化合成；判決資訊與終局報導分層顯示。

### FM-D｜沒有抵達的探望

- 外婆先把孩子衣物交給受託人，回家後克制思念。
- 她不是被阻擋在某個具體門外；「沒有抵達」是信任之路沒有走到孩子身邊的文學意象。
- 鏡頭留在未送出的布包、電話、雨夜長廊與空藤椅，不煽情重演。

### FM-B｜青絲變白頭

- 第一段：三名清代婦女梳髮、簪花並交頭接耳談論椅仔姑；這是文學化群像，不是歷史證詞。
- 第二段：兩名醫院護士交頭接耳，對話永久標示為匿名來函情境重構。
- 第三段：法院旁聽婦女群像，鏡頭依青絲、夾白、全白髮緩慢橫移。
- 第四段：鏡頭交給外婆；外婆位在法院證人席，不是旁聽席。
- 白髮是時間長卷的落點，不使用奇幻瞬間變老特效。

### FM-C｜兩個世界，同一扇門

- 椅仔姑：完整、無傷、非肖像化清代女童側影。
- 剴剴：完整、無傷、非肖像化幼童側影；可參考藍色條紋上衣的生活記憶，但不得還原真實面貌。
- 兩名孩子不相擁、不升天、不變成鬼魂；最後退成未書寫紙影，把責任交回成年守門人。

## 6. 大型半透明閩南圖章

原始圖章表已裁為12枚獨立WebP素材：`assets/img/badges/minnan-01.webp`至`minnan-12.webp`。

網站以`badge-field`在長頁面不同高度、左右與尺度配置：

- 尺寸：`clamp(260px, 24–33vw, 560px)`。
- 透明度：7.5%。
- 混合模式：`screen`。
- 徑向遮罩：保留圓章、淡化方形裁切邊界。
- 不攔截滑鼠、不進入螢幕閱讀器、不降低正文對比。

## 7. 資產清單

- `assets/img/films/`：4張電影概念長卷。
- `assets/img/side/`：10張陰翳側視角色／場景關鍵幀。
- `assets/img/badges/`：12枚圓章與原始圖章表。
- `assets/data/scenes.js`：24場單一資料來源。
- `assets/data/scene-manifest.json`：可供工程、QA與後續CMS匯入的機器可讀資料。
- `assets/vendor/gsap/`：GSAP 3.13.0與ScrollTrigger 3.13.0本地正式檔。
- `assets/js/app.js`：場次篩選、GSAP時間軸、十拍動作、逐字稿、進度拖曳、低動態與深連結。
- `assets/css/styles.css`：色彩、排版、角色關節、十姿態、舞臺與RWD。

## 8. 原創音樂掛載

本壓縮包不偽造原創音樂檔。收到使用者提供的音檔後，依以下槽位掛載：

- 前六篇：`bgm_01`至`bgm_06`。
- 第07篇：環境音景`amb_timeline_thread_room`。
- 第08篇：環境音景`amb_courtroom_after_session`。
- 結尾：`bgm_01_reprise`，最後一句前完全退出。

建議交付格式：48kHz/24-bit WAV母帶＋128/192kbps AAC或MP3網頁版；網頁整體目標約`-18 LUFS`，對話時再降8dB。未提供音檔前，網站維持靜音，不以無授權素材代替。

## 9. 部署

這是純靜態GitHub Pages網站：

1. 解壓縮。
2. 將資料夾內所有檔案推送到`https://github.com/jerryzuhow77/Justice-For-Kaikai`。
3. GitHub Repository → Settings → Pages。
4. Source選`Deploy from a branch`，Branch選`main`與`/(root)`。
5. 等待部署完成後公開網址通常為`https://jerryzuhow77.github.io/Justice-For-Kaikai/`。
